# Sessioni

Questa skill contiene i file di metodo del gruppo "Sessioni". Apri solo il file la cui riga "Usalo quando" corrisponde alla situazione, prima di rispondere. Puoi aprirne più di uno. I file stanno in questa cartella.

| File | Usalo quando |
|---|---|
| [p01-intake.md](p01-intake.md) | È la prima sessione, oppure il cliente vuole ridefinire come lavoriamo insieme. |

| [p07-lavoro-a-tempo.md](p07-lavoro-a-tempo.md) | Il cliente lavora a una consegna con un tempo stimato o dice di avere poco tempo. |
